## Included
- Custom user authentication and roles
- Administrator, Monitoring Officer, Support Officer, OFW roles
- OFW profile management
- Welfare check-ins
- Monitoring records and status tracking
- Concern and case management
- Case actions
- Support records
- Referrals
- Follow-ups
- Emergency/urgent welfare flagging
- Notifications model and page
- Reports dashboard
- Audit log model
- Django admin
- Bootstrap interface
- SQLite default for easy first run
- MySQL/MariaDB option for XAMPP

## Scope
This project is ONLY for monitoring and support information. It does not implement recruitment, job placement, payroll, money transfer, OEC processing, visa/passport processing, or online payment.
